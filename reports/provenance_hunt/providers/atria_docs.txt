API</h1><p class="lede">支持 Chat Completions、Messages 和 Responses 三种标准接口，可直接接入现有应用与 Agent 工具。</p><section id="create-key"><h2>鉴权：创建 API Key</h2><p>Atria API 使用你在控制台创建的 API Key 识别调用者。创建过程只需几步。</p><ol class="docs-steps"><li><b>1</b><div><strong>登录控制台</strong><span>使用 Google 账号登录，然后进入 API Key 页面。</span></div></li><li><b>2</b><div><strong>填写密钥名称</strong><span>使用能区分环境或应用的名称，例如 production-agent。</span></div></li><li><b>3</b><div><strong>创建并立即复制</strong><span>点击“创建密钥”后复制完整 Key。完整内容只显示一次，关闭提示后无法再次查看。</span></div></li><li><b>4</b><div><strong>安全保存</strong><span>将 Key 放入服务端环境变量或密码管理器，不要写入前端代码。</span></div></li></ol><div class="docs-callout"><span>如果 Key 丢失，请吊销旧 Key 并创建新的 Key；系统无法恢复已经隐藏的完整 Key。</span><a href="/console/keys">前往 API Key 控制台<!-- --> →</a></div></section><section id="auth"><h2>鉴权与环境变量</h2><p>所有请求都使用 Bearer API Key。Key 只在创建时完整显示一次，请保存到密码管理器或服务端环境变量。</p><h3>macOS / Linux</h3><div class="code-block"><button <!-- -->Content-Type: application/json</code></pre></div></section><section id="quickstart"><h2>非流式调用</h2><p>适合一次性获取完整回答。复制下面的命令，替换 API Key 后即可运行。</p><div class="code-block"><button class="copy-button">复制</button><pre><code>curl -X POST https://api.atria-asi.ai/v1/chat/completions \

  }&#x27;</code></pre></div></section><section id="streaming"><h2>流式调用</h2><p>适合聊天界面，模型生成的内容会持续返回。curl 会直接逐行显示结果。</p><div class="code-block"><button class="copy-button">复制</button><pre><code>curl -N -X POST https://api.atria-asi.ai/v1/chat/completions \

  }&#x27;</code></pre></div></section><section id="messages-api"><h2>Messages 接口</h2><p>兼容 Anthropic Messages API，使用 x-api-key 鉴权。适合已有 Anthropic SDK 或工具链。</p><div class="code-block"><button class="copy-button">复制</button><pre><code>curl -X POST https://api.atria-asi.ai/v1/messages \

  }&#x27;</code></pre></div></section><section id="responses-api"><h2>Responses 接口</h2><p>兼容 OpenAI Responses API，使用 input 字段提交文本或结构化输入。</p><div class="code-block"><button class="copy-button">复制</button><pre><code>curl -X POST https://api.atria-asi.ai/v1/responses \

  }&#x27;</code></pre></div></section><section id="response"><h2>理解返回结果</h2><p>三种接口的字段结构不同。下面列出最常用的正文路径、结束原因和 token 用量位置，接入时无需遍历整个 JSON。</p><div class="response-reference"><div><strong>Chat Completions</strong><code>回答正文<!-- -->: choices[0].message.content</code><code>结束原因<!-- -->: choices[0].finish_reason</code><code>Token 用量<!-- -->: usage.prompt_tokens / completion_tokens</code><code>流式增量<!-- -->: choices[0].delta.content</code></div><div><strong>Messages</strong><code>回答正文<!-- -->: content[0].text</code><code>结束原因<!-- -->: stop_reason</code><code>Token 用量<!-- -->: usage.input_tokens / output_tokens</code><code>流式增量<!-- -->: content_block_delta.delta.text</code></div><div><strong>Responses</strong><code>回答正文<!-- -->: output[0].content[0].text</code><code>结束原因<!-- -->: status</code><code>Token 用量<!-- -->: usage.input_tokens / output_tokens</code><code>流式增量<!-- -->: response.output_text.delta</code></div></div><h3>流式增量</h3><p>流式响应使用 SSE。逐行读取 data: 事件并拼接增量文本；收到 [DONE] 或对应 completed/stop 事件后结束。不要把每个事件当作一条完整回答。</p><div class="code-block"><pre><code>data: {&quot;choices&quot;:[{&quot;delta&quot;:{&quot;content&quot;:&quot;Hello&quot;}}]}

data: {&quot;choices&quot;:[{&quot;delta&quot;:{&quot;content&quot;:&quot; world!&quot;}}]}

data: [DONE]</code></pre></div><h3>Token 用量</h3><p>usage 用于控制台统计和成本观测。输入与输出 token 会在流结束后结算，因此流式请求进行中看到的用量可能暂未更新。</p></section><section id="models"><h2>模型概览与接口选择</h2><p>Atria Dawn 面向科研分析、代码开发与多轮 Agent 任务。当前提供 Atria-Dawn 一个模型，根据应用使用的 SDK 或请求格式选择接口即可。</p><h3>可用模型</h3><p>请求中的 model 字段固定使用 Atria-Dawn，名称区分大小写。点击下方 ID 可查看完整调用示例。</p><div class="model-reference"><table><thead><tr><th scope="col">Model ID</th><th scope="col">上下文窗口</th></tr></thead><tbody><tr><th scope="row"><a href="#Atria-Dawn"><code>Atria-Dawn</code> →</a></th><td>512K tokens</td></tr></tbody></table></div><p>Atria-Dawn 支持下述三种接口，以及非流式和流式调用。模型 ID 在三种接口中保持一致。</p><h3>组织适合任务的输入</h3><ol class="docs-steps model-task-list"><li><b>0<!-- -->1</b><div><strong>科研与资料分析</strong><span>提供研究问题、相关文献片段和分析范围，并明确需要的结论形式，例如证据对照、研究假设或实验方案。需要引用时，将来源信息一并传入。</span></div></li><li><b>0<!-- -->2</b><div><strong>代码与工程任务</strong><span>提供相关代码、报错信息、运行环境和验收条件，让模型围绕具体问题生成实现或修改建议；再用测试结果继续迭代。</span></div></li><li><b>0<!-- -->3</b><div><strong>多轮 Agent 工作流</strong><span>提供任务目标、可用工具和当前状态。由应用或 Agent 执行工具调用，并将结果作为后续输入交回模型，逐步推进任务。</span></div></li></ol><h3>选择调用接口</h3><p>已有项目沿用当前 SDK 对应的接口即可；通过 HTTP 直接接入时，可从 Chat Completions 示例开始。切换接口时，请同时调整输入字段和响应解析方式。</p><div class="model-reference"><table><thead><tr><th scope="col">接口与路径</th><th scope="col">输入字段</th><th scope="col">输出上限参数</th></tr></thead><tbody><tr><th scope="row"><a href="#quickstart">Chat Completions</a><code>/v1/chat/completions</code></th><td><code>messages</code></td><td><code>max_completion_tokens</code><span>或 <code>max_tokens</code></span></td></tr><tr><th scope="row"><a href="#messages-api">Messages</a><code>/v1/messages</code></th><td><code>messages</code></td><td><code>max_tokens</code></td></tr><tr><th scope="row"><a href="#responses-api">Responses</a><code>/v1/responses</code></th><td><code>input</code></td><td><code>max_output_tokens</code></td></tr></tbody></table></div><h3>理解 512K 上下文与输出长度</h3><p>512K 表示一次请求可容纳的上下文规模，包含输入内容与生成内容。系统提示、历史对话、文档片段和工具结果都会占用输入空间；组织长上下文时，需要为回答预留空间。</p><p>上下文窗口不等于单次回答长度。上表的输出上限参数以 token 为单位，接受 1–65,536 的整数，用于限制本次生成长度；实际输出还取决于停止条件和剩余上下文。它不是目标字数，也不会保证生成到该长度。</p><p>处理长文档或多轮任务时，优先保留相关材料和必要历史，明确要求的输出格式，并根据任务设置输出上限。三个推理接口不再设置应用层请求体大小上限，但仍需满足模型上下文、可用额度及接入链路的限制。</p><h3>开始调用与验证结果</h3><p>复制下方示例，使用控制台创建的 API Key 完成一次简短请求。接入 Messages 或 Responses 时，保持 model 字段为 Atria-Dawn，并使用对应的请求路径、鉴权头和输入字段。</p><p>将模型接入正式任务前，用有代表性的输入检查结果正确性、指令遵循、响应时间和 token 用量。调整提示词、工具配置或接口后，复测这些任务。</p><div class="model-example-links"><a href="#Atria-Dawn">Atria-Dawn<!-- --> →</a></div></section><section id="Atria-Dawn"><div class="doc-model-heading"><h2>Atria-Dawn</h2></div><p>下面是此模型的 Chat Completions 最小请求。先设置 ATRIA_API_KEY export ANTHROPIC_AUTH_TOKEN=$ATRIA_API_KEY
claude --model Atria-Dawn</code></pre></div><h3>限制 Read 工具读取图片和 PDF</h3><p>Atria-Dawn 接收纯文本输入。可通过 PreToolUse Hook，在 Claude Code 的 Read 工具读取图片或 PDF 前拒绝该操作；先将所需内容提取成文本，再交给模型。以下步骤需要本机已安装 Python 3。</p><h3>1. 保存拦截脚本</h3><p>将以下完整脚本保存为 block_pdf_image_read.py，记下实际绝对路径，例如 /absolute/path/block_pdf_image_read.py。示例路径只是占位符，请替换为你本机的路径。</p><div class="code-block"><button class="copy-button">复制</button><pre><code>#!/usr/bin/env python3
&quot;&quot;&quot;
PreToolUse hook: block the Read tool from reading PDF and image files.
&quot;&quot;&quot;
import json
import sys


IMAGE_EXTENSIONS = (
    &quot;.apng&quot;,
    &quot;.avif&quot;,
    &quot;.bmp&quot;,
    &quot;.gif&quot;,
    &quot;.heic&quot;,
    &quot;.heif&quot;,
    &quot;.ico&quot;,
    &quot;.jfif&quot;,
    &quot;.jpeg&quot;,
    &quot;.jpg&quot;,
    &quot;.jxl&quot;,
    &quot;.png&quot;,
    &quot;.svg&quot;,
    &quot;.tif&quot;,
    &quot;.tiff&quot;,
    &quot;.webp&quot;,
)


def main():
    hook_input = json.loads(sys.stdin.read())
    file_path = hook_input.get(&quot;tool_input&quot;, {}).get(&quot;file_path&quot;, &quot;&quot;)

    if file_path.lower().endswith(&quot;.pdf&quot;):
        reason = &quot;Reading PDF files with the Read tool is not allowed.&quot;
    elif file_path.lower().endswith(IMAGE_EXTENSIONS):
        reason = &quot;Reading image files with the Read tool is not allowed.&quot;
    else:
        sys.exit(0)

    output = {
        &quot;hookSpecificOutput&quot;: {
            &quot;hookEventName&quot;: &quot;PreToolUse&quot;,
            &quot;permissionDecision&quot;: &quot;deny&quot;,
            &quot;permissionDecisionReason&quot;: reason,
        }
    }
    print(json.dumps(output, ensure_ascii=False))

    sys.exit(0)


if __name__ == &quot;__main__&quot;:
    main()
</code></pre></div><h3>2. 合并 Hook 配置</h3><p>在 ~/.claude/settings.json 中合并以下 hooks 配置。已有 PreToolUse 时追加该条规则，不要覆盖其他设置或 Hook。若使用 CLAUDE_CONFIG_DIR 自定义配置目录，则修改该目录中的 settings.json。command 中填写脚本的绝对路径，并保留路径两侧的引号。</p><div class="code-block"><button class="copy-button">复制</button><pre><code>{
  &quot;hooks&quot;: {
    &quot;PreToolUse&quot;: [
      {
        &quot;matcher&quot;: &quot;Read&quot;,
        &quot;hooks&quot;: [
          {
            &quot;type&quot;: &quot;command&quot;,
            &quot;command&quot;: &quot;python3 \&quot;/absolute/path/block_pdf_image_read.py\&quot;&quot;,
            &quot;timeout&quot;: 5
          }
        ]
      }
    ]
  }
